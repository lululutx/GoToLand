## 刑法对比

### 核心区别对比表

| 维度          | 不构成犯罪        | 不负刑事责任（不负刑罚）       | 不处罚（含两种情形）            | 不执行               |
| ----------- | ------------ | ------------------ | --------------------- | ----------------- |
| **是否构成犯罪**  | 否（无犯罪前提）     | 是（已满足犯罪构成）         | 情形 1：否；情形 2：是         | 是（已定罪）            |
| **是否有刑罚判决** | 无（刑事程序终止）    | 无（因免责，不判处刑罚）       | 情形 1：无；情形 2：有（“免罚判决”） | 有（已生效的刑罚判决）       |
| **是否有犯罪记录** | 无（无案底）       | 无（虽构成犯罪，但不追责）      | 情形 1：无；情形 2：有（定罪留案底）  | 有（定罪判刑留案底）        |
| **法律后果核心**  | 不承担任何刑事责任    | 不承担刑罚，可能有其他处理（如管教） | 情形 1：无刑事处罚；情形 2：免予刑罚  | 刑罚暂不执行或不再执行（已判刑罚） |
| **适用阶段**    | 立案、审查起诉、审判阶段 | 审判阶段（认定犯罪后免责）      | 情形 1：各阶段；情形 2：审判阶段    | 判决生效后的执行阶段        |

### 逻辑递进关系

四个概念围绕 “**犯罪认定→责任承担→刑罚判决→刑罚执行**” 的刑事流程层层区分，核心逻辑链如下：

1. **最前端：不构成犯罪**→ 流程直接终止，无犯罪、无责任、无刑罚；
2. **次前端：不负刑事责任**→ 已构成犯罪，但因法定原因（如年龄、精神状态）不担责，无刑罚；
3. **中端：不处罚**→ 要么不构成犯罪（无刑罚），要么构成犯罪但免罚（定罪无刑罚）；
4. **最末端：不执行**→ 已定罪判刑，仅因执行阶段的特殊情况，不实际执行刑罚。

简言之：前两者是 “无刑罚”，后两者是 “有刑罚相关处理（免罚 / 不执行）”；前三者均无 “实际执行的刑罚”，仅第四者是 “已判刑罚但不执行”。


## 追缴和收缴

| 维度       | 收缴                                                                                              | 追缴                                        |
| -------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **适用对象** | 1. 违禁品（如毒品、管制刀具、假币）；<br><br>2. 直接用于实施违法行为的本人所有工具（如赌博用的骰子、盗窃用的撬锁工具）；<br><br>3. 违法所得中无法追缴或无被害人的财物 | 仅针对**违法所==得**==（通过违法活动获取的财物，如诈骗的钱款、盗窃的物品） |
| **财物性质** | 财物本身具有非法性（即使未用于违法，持有也违法）                                                                        | 财物本身可能具有合法性（如钱款、普通物品），但来源 / 取得方式违法        |
| **处理结果** | 收缴后依法**没收、销毁或上缴国库**（无返还可能）                                                                      | 追缴后优先**退还给被害人**；无被害人的，上缴国库                |
| **适用场景** | 行政案件（治安、行政违法）、刑事案件均适用                                                                           | 行政案件、刑事案件均适用，但刑事案件中常与 “责令退赔” 结合使用         |


## 证据的有效性

人7物5照10

以下无效

（一）辨认不是在调查人员、侦查人员主持下进行的；
（二）辨认前使辨认人见到辨认对象的；
（三）辨认活动没有个别进行的；
（四）辨认对象没有混杂在具有类似特征的其他对象中，或者供辨认的对象数量不符合规定的；
（五）辨认中给辨认人明显暗示或者明显有指认嫌疑的

以下解释说明之后有效

（一）主持辨辨认的侦查人员少于二人的；
（二）没有向辨认人详细询问辨认对象的具体特征的；
（三）对辨认经过和结果没有制作专门的规范的辨认笔录，或者辨认笔录没有侦查人员、辨认人、见证人的签名或者盖章的；
（四）辨认记录过于简单，只有结果没有过程的；
（五）案卷中只有辨认笔录，没有被辨认对象的照片、录像等资料，无法获悉辨认的真实情况的

## 案件的结束

#### 行政

**结案**：==正式结果==1、不处罚决定。2、调解已履行。3、做出处罚决定已执行。4、转为刑事。5、做出处理决定后嫌疑人死亡或其他原因导致无法或无需执行的。

**终止调查**：==戛然而止==1、没有违法事实。2、违法行为已过追溯时效的。3、违法嫌疑人死亡的。4、其他情形。

#### 刑事

**侦察终结**：==正式结果==事实轻，证据充、应追究、手续完备、罪名定。

**撤案**：==戛然而止==转为行政、显著轻、过时效、特赦告诉和死掉
