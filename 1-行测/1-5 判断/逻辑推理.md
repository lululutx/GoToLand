

# 除非

- “除非 A，否则不 B”：后推前（B→A）；
- “除非 A，否则 B”：否前推后（¬A→B）；
- “否则 B”：补全 A 后同 “除非 A，否则 B”（¬A→B）。


# 模态矛盾关系

 “必然” 与 “可能”  必然一真一假。


例如：“明天必然下雨” 的矛盾不是 “明天必然不下雨”（两者可能同假，比如明天可能阴天），而是 “明天可能不下雨”（只要存在 “不下雨” 的可能性，原命题就为假）。

例如：“这次考试可能及格” 的矛盾不是 “这次考试可能不及格”（两者可能同真，比如成绩不确定时），而是 “这次考试必然不及格”（只要 “一定不及格”，原命题就为假）。

模态矛盾关系与直言命题（AEIO）的矛盾关系逻辑结构一致，可对比理解：

  
| 模态命题矛盾对      | 直言命题（AEIO）矛盾对             | 共同特点                  |
| ------------ | ------------------------- | --------------------- |
| 必然 P ↔ 可能非 P | 所有 S 是 P（A）↔ 有的 S 不是 P（O） | 全称 / 必然与特称 / 可能否定矛盾   |
| 必然非 P ↔ 可能 P | 所有 S 不是 P（E）↔ 有的 S 是 P（I） | 全称 / 必然否定与特称 / 可能肯定矛盾 |
|              |                           |                       |

# 或者和要么

“或者 A，或者 B” 与 “A 或 B” 是完全等价的，都属于**相容选言命题**

- 当 A 真、B 真时，命题为真；
- 当 A 真、B 假时，命题为真；
- 当 A 假、B 真时，命题为真；
- 只有 A 假且 B 假时，命题为假。

“要么 A，要么 B” 的含义（即**不相容选言命题**），不包含当 A 真、B 真时（例如：“要么去北京，要么去上海”，隐含不能同时去）。
